## Part 1: Path Variables

### 1. `GET /users/{name}` - Single Path Variable

**Description:** Extract a single path variable

**Request:**
```bash
curl http://localhost:8101/users/john
```

**Response:**
```json
{
  "handler": "GetUserByName",
  "name": "john",
  "message": "Looking up user: john"
}
```

**Code:**
```go
r.HandleFunc("/users/{name}", GetUserByName)

func GetUserByName(w http.ResponseWriter, r *http.Request) {
    vars := mux.Vars(r)
    name := vars["name"]  // Extract "john"
}
```

---

### 2. `GET /users/{id:[0-9]+}` - Path Variable with Regex

**Description:** Only matches numeric IDs

**Request:**
```bash
curl http://localhost:8101/users/123
```

**Response:**
```json
{
  "handler": "GetUserByID",
  "id": "123",
  "message": "Looking up user with ID: 123"
}
```

**Note:** `/users/john` would return 404 (doesn't match regex)

**Code:**
```go
r.HandleFunc("/users/{id:[0-9]+}", GetUserByID)
```

---

### 3. `GET /articles/{category}/{id}` - Multiple Path Variables

**Description:** Extract multiple path variables

**Request:**
```bash
curl http://localhost:8101/articles/tech/42
```

**Response:**
```json
{
  "handler": "GetArticle",
  "category": "tech",
  "article_id": "42",
  "message": "Article 42 in category: tech"
}
```

**Code:**
```go
r.HandleFunc("/articles/{category}/{id}", GetArticle)

func GetArticle(w http.ResponseWriter, r *http.Request) {
    vars := mux.Vars(r)
    category := vars["category"]
    id := vars["id"]
}
```

## Part 2: Query Parameters

### 6. `GET /search` - Basic Search

**Description:** Extract query parameters from URL

**Request:**
```bash
curl "http://localhost:8101/search?q=golang&limit=20"
```

**Response:**
```json
{
  "handler": "SearchHandler",
  "query": "golang",
  "limit": 20,
  "all_params": {
    "q": ["golang"],
    "limit": ["20"]
  }
}
```

**Code:**
```go
func SearchHandler(w http.ResponseWriter, r *http.Request) {
    query := r.URL.Query()
    
    // Get single value
    q := query.Get("q")
    limitStr := query.Get("limit")
    
    // Parse with default
    limit := 10
    if limitStr != "" {
        limit, _ = strconv.Atoi(limitStr)
    }
}
```

## Part 3: Combined Path + Query

### 9. `GET /users/{id}/posts` - Path + Query Together

**Description:** Combine path variables with query params

**Request:**
```bash
curl "http://localhost:8101/users/123/posts?limit=5&offset=10"
```

**Response:**
```json
{
  "handler": "GetUserPosts",
  "user_id": "123",
  "pagination": {
    "limit": 5,
    "offset": 10
  },
  "posts": [...]
}
```

**Code:**
```go
r.HandleFunc("/users/{id}/posts", GetUserPosts)

func GetUserPosts(w http.ResponseWriter, r *http.Request) {
    // Path variable
    vars := mux.Vars(r)
    userID := vars["id"]
    
    // Query params
    query := r.URL.Query()
    limit := query.Get("limit")
    offset := query.Get("offset")
}
```

## Quick Reference

### Extract Path Variables
```go
vars := mux.Vars(r)
value := vars["variableName"]
```

### Extract Query Parameters
```go
query := r.URL.Query()
single := query.Get("key")      // First value
multiple := query["key"]        // All values as []string
```

### Common Regex Patterns
| Pattern | Matches |
|---------|---------|
| `{id}` | Anything |
| `{id:[0-9]+}` | Numbers only |
| `{slug:[a-z0-9-]+}` | URL slugs |
| `{path:.*}` | Everything (greedy) |

---

## Key Takeaways

1. **Path variables** use `{name}` syntax in route pattern
2. **Regex patterns** use `{name:pattern}` syntax
3. **Extract path vars** with `mux.Vars(r)["name"]`
4. **Extract query params** with `r.URL.Query().Get("key")`
5. **Combined** = path vars for resource ID, query params for filters/pagination
