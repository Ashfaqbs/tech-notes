### 1. Basic Authentication

**How it works:** Username/password sent via `Authorization: Basic` header

#### Protected Endpoint
```bash
curl -u admin:admin123 http://localhost:8081/basic/protected
```

**Response:**
```json
{
  "message": "Access granted!",
  "user": {
    "id": "1",
    "username": "admin",
    "role": "admin"
  }
}
```

#### Admin-Only Endpoint (Try with regular user)
```bash
curl -u user:user123 http://localhost:8081/basic/admin
```

**Response:** `403 Forbidden`
```
Admin access required
```

#### Code
```go
func BasicAuthMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        authHeader := r.Header.Get("Authorization")
        
        // Parse "Basic base64"
        parts := strings.SplitN(authHeader, " ", 2)
        decoded, _ := base64.StdEncoding.DecodeString(parts[1])
        creds := strings.SplitN(string(decoded), ":", 2)
        username, password := creds[0], creds[1]
        
        // Validate
        user, exists := users[username]
        if !exists || !checkPassword(password, user.Password) {
            http.Error(w, "Unauthorized", 401)
            return
        }
        
        next.ServeHTTP(w, r)
    })
}
```

### 2. JWT Authentication

**How it works:** Login to get token, then use `Bearer` token in requests

#### Step 1: Login
```bash
curl -X POST http://localhost:8081/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

#### Step 2: Use Token
```bash
curl -H "Authorization: Bearer <token>" http://localhost:8081/jwt/protected
```

**Response:**
```json
{
  "claims": {
    "user_id": "1",
    "username": "admin",
    "role": "admin",
    "exp": 1776357855,
    "iat": 1776354255
  },
  "message": "Access granted!"
}
```

#### Get Profile
```bash
curl -H "Authorization: Bearer <token>" http://localhost:8081/jwt/profile
```

#### Code
```go
// Generate JWT
func generateJWT(user User) (string, error) {
    claims := jwt.MapClaims{
        "user_id": user.ID,
        "username": user.Username,
        "role": user.Role,
        "exp": time.Now().Add(1 * time.Hour).Unix(),
    }
    token := jwt.NewWithClaims(jwt.SigningMethodHS256, claims)
    return token.SignedString(jwtSecret)
}

// Validate JWT
func JWTAuthMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        authHeader := r.Header.Get("Authorization")
        tokenString := strings.TrimPrefix(authHeader, "Bearer ")
        
        token, err := jwt.Parse(tokenString, func(token *jwt.Token) (interface{}, error) {
            return jwtSecret, nil
        })
        
        if err != nil || !token.Valid {
            http.Error(w, "Invalid token", 401)
            return
        }
        
        next.ServeHTTP(w, r)
    })
}
```

### 3. API Key Authentication

**How it works:** Long-lived key sent via `X-API-Key` header

#### Protected Endpoint
```bash
curl -H "X-API-Key: sk-live-abc123xyz" http://localhost:8081/api/v1/data
```

**Response:**
```json
{
  "data": ["item1", "item2", "item3"],
  "message": "API access granted!",
  "user_id": "user-1"
}
```

#### Missing API Key
```bash
curl http://localhost:8081/api/v1/data
```

**Response:** `401 Unauthorized`
```
Missing X-API-Key header
```

#### Invalid API Key
```bash
curl -H "X-API-Key: invalid-key" http://localhost:8081/api/v1/data
```

**Response:** `401 Unauthorized`
```
Invalid API key
```

#### Code
```go
func APIKeyMiddleware(next http.Handler) http.Handler {
```

### 4. OAuth 2.0 (GitHub)

**How it works:** Redirect to GitHub for authorization

#### Step 1: Initiate OAuth
```bash
# Visit in browser
http://localhost:8081/oauth/github
```

This redirects to GitHub login page.

#### Step 2: Callback
GitHub redirects back to:
```
http://localhost:8081/oauth/github/callback?code=AUTH_CODE&state=RANDOM_STATE
```

#### Code
```go
func GitHubOAuthHandler(w http.ResponseWriter, r *http.Request) {
    state := generateRandomString(32)
    oauthStates[state] = state  // CSRF protection
    
    authURL := fmt.Sprintf(
        "https://github.com/login/oauth/authorize?client_id=%s&redirect_uri=%s&state=%s",
        os.Getenv("GITHUB_CLIENT_ID"),
        "http://localhost:8081/oauth/github/callback",
        state,
    )
    http.Redirect(w, r, authURL, 307)
}
```

## Password Hashing

```go
import "golang.org/x/crypto/bcrypt"

// Hash password
func hashPassword(password string) string {
    hash, _ := bcrypt.GenerateFromPassword([]byte(password), bcrypt.DefaultCost)
    return string(hash)
}

// Verify password
func checkPassword(password, hash string) bool {
    err := bcrypt.CompareHashAndPassword([]byte(hash), []byte(password))
    return err == nil
}
```

## Authentication Comparison

| Method | Security | Complexity | Best For |
|--------|----------|------------|----------|
| **Basic Auth** | Low | Very Low | Internal services |
| **JWT** | High | Medium | REST APIs, mobile apps |
| **API Key** | Medium | Low | Server-to-server |
| **OAuth 2.0** | High | High | Social login |

## Key Takeaways

1. **Basic Auth** - Simple but credentials sent with every request
2. **JWT** - Stateless, includes claims, can't easily revoke
3. **API Key** - Good for server-to-server, long-lived
4. **OAuth** - Don't handle passwords, use providers like GitHub/Google
5. **Always hash passwords** with bcrypt or argon2
6. **Use HTTPS** in production for all auth methods
7. **Implement role-based access** for fine-grained permissions
